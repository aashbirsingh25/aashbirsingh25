### 🚚 RideTrack — Real-Time Delivery Tracking & Event-Driven Dispatch Platform

[![GitHub](https://img.shields.io/badge/GitHub-Repo-2563EB?style=flat-square&logo=github&logoColor=white)](https://github.com/aashbirsingh25/ridetrack)
[![Live Demo](https://img.shields.io/badge/Live-Demo-7C3AED?style=flat-square&logo=vercel&logoColor=white)](https://ridetrack-q1ta.vercel.app)

**Stack:** NestJS · Next.js · FastAPI · PostgreSQL · Redis · RabbitMQ · Docker · Kubernetes · Helm · Terraform · Prometheus · Grafana · WebSockets · AWS EC2

- Architected a **5-service event-driven microservices platform** using RabbitMQ pub/sub to automatically match riders to orders in real time, eliminating manual dispatch entirely
- Delivered live tracking with WebSocket- and Redis-based GPS broadcasting at **sub-3-second latency**, integrated with OSRM for road-based routing
- Trained and deployed a Scikit-learn regression model for ETA prediction (**MAE 1.52 min, R² 0.99**); containerized with Docker/Kubernetes/Helm, provisioned infra with Terraform, instrumented with Prometheus/Grafana, and automated CI/CD via GitHub Actions — independently deployed and debugged on AWS EC2
